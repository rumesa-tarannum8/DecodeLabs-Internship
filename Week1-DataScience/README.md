# Titanic Dataset Analysis

## Project Description
This project performs Exploratory Data Analysis (EDA) on the Titanic Passenger Dataset using Python, Pandas, and Matplotlib.

## Tasks Completed
- Data Loading
- Missing Value Analysis
- Data Cleaning
- Statistical Analysis
- Correlation Analysis
- Data Visualization

## Dataset Information
- Total Records: 891
- Total Columns: 12

## Technologies Used
- Python
- Pandas
- Matplotlib

python3 data_analysis.py
